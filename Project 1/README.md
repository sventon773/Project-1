UVM Student Ski & Snowboard Guide
This is a multi-page website tat serves as a guide for the University of Vermont students looking to explore skiing and snowboarding spots around Burlington

Key Features
- uses header, nav, section, article, and footer tags
- includes three pages 'index.html' , 'resorts.html' , and 'tips.html'
- Has a table which compares mountian distance, pass types, and key features of the mountians
- Uses a Flexbox for cars and the navigation and a media query to adapt to mobile screens
- Includes a youtube video of someone skiing at jay peak
